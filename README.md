# guchao-brains-skill

> 一个「导师思维模拟器」：把一位果树学导师的思维框架、证据标准与学术表达，炼成一个可运行的 Claude/ZCode Skill。

## 这是什么

本 Skill 基于一位梨果树学研究者（**化名保护：谷超老师**，南京农业大学梨创新团队）的 **26 篇公开发表论文**（2017–2025）构建：

- **26 篇论文逐篇一手 PDF 核验**（标题模板/作者角色/通讯栏/摘要 hedging/基金与数据 accession）
- 6 篇深读（含 Discussion 与 Methods 层）
- 26 篇证据分级精读笔记（每篇含证据链/证据边界/下一步实验）
- 1 份研究方向图谱（两条主线：梨自交不亲和 × 果实成熟乙烯调控）
- 网络侧调研（职务、被引、合作网络署名反推）

从中提炼出 **5 个心智模型、10 条决策启发式、15 项表达 DNA 指纹**，以及一个「他怎么拆问题」的九场景引擎（课题讨论/数据评审/文献可信度/方案评审/方向判断/职业写作/开题答辩/审稿回复/投稿策略）。

## 能干什么

| 场景 | 你会得到 |
|---|---|
| 课题讨论 | 方案在见真人导师前先被"证据等级三连问"过滤一遍 |
| 数据评审 | 贴出结果，默认走"测量可靠性→排除混杂→判别实验"路径 |
| 文献可信度 | 扫动词与证据是否匹配、划"已闭合/未闭合"分界线 |
| 方案评审 | 平台复用检查→证据配置→阴性对照前置→重复维度 |
| 方向判断 | 用未闭合清单回答，对热点默认保守 |
| 写作投稿 | 证据-动词对齐表自检、三种标题模板、审稿回复策略 |

## 安装

把整个目录复制到你的技能目录：

```
~/.agents/skills/guchao-brains-skill/     # ZCode / 自定义技能目录
~/.claude/skills/guchao-brains-skill/     # Claude Code
```

然后对 AI 说：**「用谷老师的视角……」**「问问谷老师」「模拟谷老师」即可激活。

## 诚实边界（重要，必读）

- **这是思维风格模拟，不是本人**。基于公开论文与公开记录构建，不构成其本人观点。
- **口语表达无任何一手材料**（无访谈/报告实录）：中文口语风格是"学术普通话+英文术语夹用"的推断模板。输出中的引号只用于引用论文原句。
- **可见的只是"发表出来的思维"**：组会讨论、方案取舍、失败项目的真实决策不可见。对未公开事务（经费、人事、学生评价）的任何"立场"都是编造，本 Skill 拒绝回答。
- **预演 ≠ 决策**：可用于准备组会、打磨方案表达；选题/毕业/经费等真实决策必须与本人确认。
- 对真实人物的模拟请保持善意：本 Skill 用于科研训练与讨论预演，不得用于冒充、欺骗或损害其名誉。

## 隐私说明

本开源版已做脱敏处理：

- 不包含任何使用者个人信息（姓名/学号/路径）
- 不包含使用者自己的研究方案（`references/sources/研究方案/` 为空目录占位——使用者可放入自己的方案，Skill 讨论课题时会读取）
- 论文 PDF 不随仓库分发（尊重版权）；`references/sources/精读笔记/` 内的笔记已覆盖其机制内容

## 目录结构

```
guchao-brains-skill/
├── SKILL.md                      # 主文件：角色扮演规则+心智模型+场景引擎
└── references/
    ├── research/                 # 调研档案（6维度调研+逐篇一手精读档案+验证测试）
    └── sources/
        ├── 精读笔记/             # 26篇论文的证据分级精读笔记
        ├── 文档/                 # 研究方向图谱等综合文档
        └── 研究方案/             # （空，使用者自填）
```
